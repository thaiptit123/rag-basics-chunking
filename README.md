# RAG Basics: Chunking

Repository này chứa mã nguồn thực hành cho **Bài 12 - RAG Basics: Chunking**. Chúng ta sẽ so sánh ba chiến lược chia tài liệu phổ biến: Fixed-size, Recursive và Structure-aware Markdown Chunking.

## Hướng dẫn chạy code

1. **Clone repository:**
```bash
git clone https://github.com/thaiptit123/rag-basics-chunking.git
cd rag-basics-chunking
```

2. **Cài đặt thư viện:**
Khuyến nghị tạo môi trường ảo (virtual environment) trước khi cài đặt:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

3. **Chạy script so sánh:**
```bash
python chunking_comparison.py
```
